# Brazilian Fire BBQ — website

Static site (HTML/CSS/JS, no build step). Deploys to Vercel as-is.

- `index.html` – page content
- `styles.css` – design
- `main.js` – animations, menu tabs, gallery lightbox, quote form (opens SMS/WhatsApp)
- `assets/img` – photos (WebP), `assets/video` – muted MP4 loops + posters

Local preview: `npx serve .`
